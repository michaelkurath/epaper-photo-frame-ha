# Home Assistant App: ePaper Photo Frame

Turns a public shared Google Photos album into six-colour frames for a DIY
Spectra 6 display. Select either the 7.3-inch 800 x 480 EE04 profile or the
13.3-inch 1200 x 1600 EE02 profile. Includes an Ingress dashboard and a
separate token-protected LAN API for the ESP32 controller.
